Backup & Restauração

Exporte e importe todos os dados do sistema em formato JSON

Backup completo do banco
Baixa ou restaura tudo da Manutenção (ativos, rotinas, publicações, OT, CQ, ocorrências, empresas, arquivo e usuários). Também aceita o export JSON do Firebase antigo. Só administradores.
Exportar Backup
Gera um arquivo .json com todos os dados: ativos, rotinas, tarefas, publicações e configurações.
Nenhum export realizado nesta sessão
Restaurar Backup
Importa um arquivo .json gerado por este sistema. Atenção: todos os dados atuais serão substituídos.
Arraste o arquivo aqui
ou clique para selecionar
Arquivar histórico de atividades
Publicações com mais de 12 meses saem do banco principal e vão para um arquivo compactado, sem perda de dados. Elas continuam consultáveis (carregadas sob demanda), ficam somente leitura e cada grupo arquivado guarda um hash de integridade.
Atenção ao restaurar: a operação substitui permanentemente todos os dados atuais pelo conteúdo do arquivo importado. Faça sempre um export antes de restaurar.
